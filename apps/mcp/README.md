# gbfs-france-mcp

MCP server for live bike-share availability in France (GBFS feeds from transport.data.gouv.fr): `search_networks`, `nearby_stations`, `get_station`.

```json
{
  "mcpServers": {
    "gbfs-france": { "command": "npx", "args": ["-y", "gbfs-france-mcp"] }
  }
}
```

Docs, coverage and licences: https://github.com/Timi-Duban/gbfs-france
